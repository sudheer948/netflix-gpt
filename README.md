# 🎬 AI-Powered Netflix Clone

A production-style Netflix-inspired movie streaming and recommendation platform built using modern React ecosystem technologies with AI-powered movie search and recommendation features.

---

## 🚀 Live Demo

https://netflixgpt-7ad63.web.app/browse

---

# ✨ Features

## 🎥 Netflix-Style Browsing Experience

* Dynamic movie browsing interface
* Responsive Netflix-inspired UI
* Hero banners & background trailers
* Movie categories with horizontal carousels
* Dynamic movie posters and cards

---

## 🤖 AI-Powered Movie Recommendation System

* Natural language movie search
* AI-generated movie recommendations
* Integrated Groq-hosted Llama 3.1 model
* Smart movie suggestion workflow
* Dynamic TMDB fetching based on AI responses

Example:

> “Suggest emotional sci-fi movies with mind-blowing endings”

---

## 🔐 Authentication & User Management

* User Sign Up / Login / Logout
* Firebase Authentication integration
* Protected routes
* Session persistence
* Form validation & error handling
